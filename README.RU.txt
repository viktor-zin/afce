AFCE — редактор блок-схем алгоритмов
-----------------------------------------------------
Программа предназначена для создания, редактирования, печати и экспорта
блок-схем алгоритмов (ГОСТ 19.701-90), генерации по ним исходного кода
на 13 языках программирования и построения блок-схем по исходному коду
на C и C++ (Файл → Импорт из исходного кода, Ctrl+I).

Сборка: Qt 6 и CMake, см. BUILDING.md.

Программа распространяется на условиях общественной лицензии GNU
(GPL версии 2 или 3).
